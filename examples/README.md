# Example data — SYNTHETIC

Both CSV files here are **synthetic**. They were generated by `scripts/make_examples.py` and are not measurements. Each file starts with comment lines saying so, and BenchCheck labels them SYNTHETIC in the UI and in every exported report.

## How they were generated

`benchcheck/synth/thinfilm.py` simulates a thin-film electrode with two independent one-electron redox sites, a stand-in for the two-step lithium insertion/extraction of a spinel such as LiMn₂O₄:

| Component | Model | Parameters (both examples) |
|---|---|---|
| Redox sites | Butler–Volmer kinetics, n = 1, α = 0.5 | E⁰ = 0.80 V and 0.95 V; 0.15 C each; k⁰ = 0.02 s⁻¹ |
| Double layer | C<sub>dl</sub>·dE/dt with a 2 s relaxation at vertices | C<sub>dl</sub> = 0.04 F |
| Side reaction | irreversible anodic Tafel current, i₀·exp((E − 1.20 V)/0.05 V) | i₀ = 0.2 mA |
| Loss of oxidized state | first-order, rate k·exp((E − 1.20 V)/0.04 V) | k = 2×10⁻³ s⁻¹ |
| Noise | Gaussian, fixed seed 7 | σ = 4 µA |
| Waveform | 1 mV staircase at 1 mV/s, start 0.30 V, positive first, 3 cycles | |

Potentials are on an illustrative Ag/AgCl (3 M KCl) scale. Peak positions and currents are chosen for illustration; they are not fitted to any publication.

| File | Upper vertex | Result |
|---|---|---|
| `synthetic_lmo_clear_return.csv` | 1.10 V | Side current and loss are negligible: clear, mirror-image return peaks. |
| `synthetic_lmo_weak_return.csv` | 1.25 V | Above ≈1.15 V the side current and the loss term act: weak return peaks, charge imbalance, current rising at the vertex, and strong cycle-to-cycle fading. This is a deliberately exaggerated stress case. |

The two files come from the **same model**; only the vertex differs. That lets the demo show the outcome of BenchCheck's recommended next check ("pull the vertex back") without BenchCheck being told anything about the generator.

## Metadata files

`*.meta.json` holds what the UI loads with each example:

- `mapping`, `units`: column mapping (`time/s`, `Ewe/V`, `<I>/mA`).
- `metadata`: the hypothetical experiment (LiMn₂O₄ composite, 1 M LiCl, aqueous, Ag/AgCl 3 M KCl, 1 mV/s, 0.7 mg, 25 °C, Pt counter). Electrode area, pH and iR compensation are **intentionally missing** so the missing-metadata checks are visible.
- `generator.parameters`: the exact model parameters.
- `ground_truth`: per-cycle Faradaic-only peak ratios and charge ratio from the model's components, used by `scripts/evaluate.py`.

Regenerate with `python scripts/make_examples.py`. The output is deterministic.
