# Project skills

- `hallmark/`: vendored from https://github.com/Nutlope/hallmark (commit 7ec8682, MIT License, see `hallmark/LICENSE`). A design skill for building web pages that look designed rather than generated. Invoke with `/hallmark <prompt>`, `/hallmark redesign <path>` or `/hallmark audit <path>`. Its optional scripts need Node (and Puppeteer for screenshots); `scripts/imagegen.mjs` only runs with a `TOGETHER_API_KEY`. `scripts/install-hook.mjs` (which edits Claude settings) has not been run.
